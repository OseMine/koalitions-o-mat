# Koalitions-O-Mat – Review vom 2026-08-02 (Bugfix-Lauf, Issue #17: Swipe-Handler)

Fokus: Umsetzung der im 4. Lauf (`reports/review-2026-08-02-d.md`) bestätigten Befunde zu Issue #17 („The error of scrolling through the tabs when scrolling vertically is still there"). Alle Fixes in `script.js` umgesetzt und per Node gegen die echten Datendateien verifiziert (`node --check script.js` OK, alle JSON valide, Swipe-Simulation, Share-Parsing-Test, Koalitions-/Sitzwerte unverändert).

## P1 – Bugs (Issue #17)

- [x] **Swipe-Handler ohne `touchmove`-Tracking** – Der Handler (`script.js:1620-1657`) prüfte nur Start-/Endkoordinate; diagonale Scroll-Flicks (`diffX=80/diffY=95`, `diffX=72/diffY=84`) passierten die 1.2×-Regel. Fix: neuer `touchmove`-Listener bricht die Geste ab, sobald irgendwann `|deltaY| > |deltaX|` ist. Simuliert: beide reproduzierten Fälle lösen keinen Tab-Wechsel mehr aus, ein sauberer horizontaler Swipe (120/10) weiterhin schon.
- [x] **Swipe auf gesamten `.container` gebunden** – Die Geste wird jetzt ausschließlich auf der `.tabs`-Leiste ausgelöst statt am `.container`. Vertikaler Scroll im Inhaltsbereich (Fragen, Koalitionen, Ergebnisse) kann damit nie mehr einen Tab wechseln; die Ausnahme-Liste (`.election-toggles/.cmp-wrap/.tr-detail-table`) entfällt.
- [x] **`swipeDisabled` wird bei `touchcancel` nicht zurückgesetzt** – `touchend`/`touchcancel` setzen das Flag jetzt zuverlässig zurück; zusätzlich `e.touches.length === 1`-Guard gegen Multi-Touch.

## P2 – Fehlende Features

- [x] **Ausschluss-Checkboxen für Parteien < Sperrklausel wirkungslos** – `populatePartyDropdowns()` (`script.js:403-413`) rendert die Checkboxen jetzt nur noch für Parteien ≥ Sperrklausel – exakt die Menge, die `berechneKoalitionen()` (script.js:468-470) berücksichtigt. Verifiziert für alle 4 Wahlen (Bund: AfD/CDU/CSU/GRÜNE/LINKE/SPD, Berlin: +BSW unter 5 % nicht mehr gelistet, usw.). Das `partyFilter`-Dropdown listet weiterhin alle antwortenden Parteien (gewollt: Filter auf Ergebnisliste).

## P3 – Verbesserungen

- [x] **Hartkodierter Tabellenkopf „Frage" in `updatePartyComparison()`** – nutzt jetzt `t('questionCol')` (script.js:1425), konsistent zu `togglePartyDetail()`.
- [x] **„Ergebnis teilen" im Koalitionen-Tab ohne Test blockiert** – `shareResults()` (`script.js:82-113`) berechnet `&c=` vor dem Leer-Check und erlaubt das Teilen der reinen Koalitions-Sicht ohne beantwortete Fragen; `parseShareHash()` akzeptiert leere `&a=` (`([^&]*)`). Verifiziert: `#w=btw2029&a=&c=mehrheit%7C20%7CCDU/CSU%7CAfD` wird geparst und stellt die Koalitions-Sicht wieder her; Alt-Links (`0j1n3j`) unverändert.
