## P1 – Bugs

- [ ] **Rein neutrale Nutzer-Antworten → 0 % für alle Parteien trotz „X/X Fragen beantwortet"** – `showTestResults()` (script.js:817-837): `m`-Antworten werden komplett übersprungen (`if (!ua || ua === 'm') return`), dadurch ist `total=0` und `match=0` für jede Partei; `totalAnswered` (script.js:847) zählt `m` dagegen als beantwortet. Verifiziert per Node: 45×`m` in btw2029 → alle 7 Parteien 0,0 %, Anzeige „45/45 Fragen beantwortet" + „Beste Übereinstimmung 0,0 %" (stabile Sortierung → AfD zuerst). Betrifft ebenso `berechneUserMatchFuerKoalition()` (script.js:475-488, „Mit Ihnen"-Balken 0 %) und `berechneUserMatchNachThema()` (script.js:726-745). Fix: bei `total===0` „–"/„zu wenig Antworten" statt 0 % anzeigen oder nur j/n-Antworten zählen.

## P2 – Fehlende Features

- [ ] **`saveTestResult()` speichert Historie auch bei 0 verwertbaren Antworten** – `showTestResults()` (script.js:951) ruft `saveTestResult` ohne Guard; ein komplett übersprungener Test landet als „0,0 % AfD"-Eintrag in der Historie und verdrängt via `createTopicChart()` (script.js:1198, `.pop()`) das letzte echte Ergebnis aus der Themenverteilung. Fix: Speichern nur bei mindestens einer j/n-Antwort.
- [ ] **Kein Transparenz-Hinweis, dass Koalitionen rein mathematisch sind** – Koalitionen wie AfD+GRÜNE+LINKE+SPD (btw2029) oder AfD+LINKE (ltw) werden als „mögliche Koalition" gelistet, obwohl AfD–GRÜNE bei 0 % Paar-Übereinstimmung liegt (verifiziert). Methodik-Box (index.html:127-130) und README („mögliche Koalitionen") klären nicht, dass keine politische Realisierbarkeit geprüft wird.
- [ ] **Kein Hinweis, dass neutrale Antworten die Frage aus dem Match entfernen** – Methodik-Box erklärt die 2×-Gewichtung, aber nicht den `m`-Effekt (Frage fliegt aus Zähler und Nenner); ohne Hinweis wirken 0 %-Ergebnisse nach rein neutraler Beantwortung wie ein Fehler.
- [ ] **„Ergebnis teilen"-Button im Koalitionen-Tab teilt den Test, nicht die Koalitions-Sicht** – `shareResults()` (script.js:81) kodiert nur `userAnswers` + wichtige Fragen; Filter des Koalitionen-Tabs (Mindestübereinstimmung, Ausschlüsse, Typ) gehen verloren. Button (index.html:132) entweder verschieben oder Koalitions-Parameter mit kodieren.
- [ ] **Partei-Filter-Dropdown inkonsistent mit dem Ergebnis** – FDP/BSW (btw2029) antworten auf Fragen und erscheinen im Ergebnis, fehlen aber im Filter (script.js:350-355, nur Parteien ≥ Sperrklausel); die Ausschluss-Checkboxen (script.js:357-365) enthalten sie dagegen. Beide Listen aus derselben Quelle speisen.
- [ ] **Cross-Election-Leak bei fehlgeschlagenem `fragen.json`** – `setActiveElection()` (script.js:211) `window.parteienData = data.fragen || window.parteienData` behält bei `fragen.json`-Ladefehler die Fragen der vorherigen Wahl (Test/Koalitionen rechnen mit falschem Fragenkatalog). Auf null zurücksetzen statt alten Wert weiterreichen.
